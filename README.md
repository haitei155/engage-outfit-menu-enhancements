# Fire Emblem Engage — 衣装、饰品与菜单增强 v0.3

[English](README.en.md)

在战斗准备界面直接进入装饰品店，打开实时 3D 换装窗口；换装后返回即可刷新战场形象，方便开战前搭配衣装与饰品。v0.3 的主要更新是为支持翻页的页面补上右上角 ZL/ZR 翻页提示，让可用操作一目了然；同时扩展转职、纹章士戒指／手镯与能力一览、整理持有物品、出售和戒指·手镯图鉴的翻页支持。插件诊断日志默认关闭。

本项目基于 **SierraSak** 的 [EngageAcc_Code](https://github.com/SierraSak/EngageAcc_Code) / [Expanded Accessory Slots](https://gamebanana.com/mods/512066) 修改并扩展。感谢原作者 SierraSak 提供饰品槽实现与资源。角色使用七个可用饰品分类；Mask 16 不作为角色可用槽。保留上游底层八项存储布局和 version 1 存档格式，新增功能见下文。

**必须先安装 [Cobalt](https://github.com/Raytwo/Cobalt)。** 感谢 **Raytwo** 开发并维护 Cobalt，为本项目提供 MOD 加载与扩展基础。

当前编译版面向《火焰纹章 Engage》2.0.0，使用 Cobalt 1.31.0 作为兼容基线。

## v0.3 新增内容

### 右上角翻页提示

**本版重点更新：为支持翻页的页面补上右上角操作提示。** 原生 **ZL/ZR 翻页**图标与文字放在现有按键提示的最后，随当前页面和可操作状态更新。打开能力一览时显示该窗口的操作；关闭返回纹章士戒指／手镯页后，恢复该页的完整按键说明。

翻页文字支持简体中文、繁体中文、日文和英文；其余原生文案沿用游戏语言。调整过的操作同步显示原生**右摇杆按下**图标。“按下右摇杆”指按压右摇杆的按钮。

### 新增翻页页面与操作

本版将翻页扩展到**转职职业列表、纹章士戒指／手镯列表及能力一览、整理持有物品、出售和戒指·手镯图鉴**。

列表统一使用 **ZL 向上翻一页、ZR 向下翻一页**，按当前界面的可见行数移动。支持单次按下和长按连续翻动，首尾停止，不循环跳转；选择、详情与能力预览随游标更新。整理持有物品仅翻动当前正在操作的列表。

| 页面 | ZL / ZR | 右摇杆按下 | 其他说明 |
| --- | --- | --- | --- |
| 转职职业列表 | 向上 / 向下翻一页 | — | L/R 切换单位；取消原 ZR 职业排序 |
| 纹章士戒指／手镯列表 | 向上 / 向下翻一页 | 打开能力一览 | 替代原 ZR 打开操作 |
| 能力一览 | 向上 / 向下翻一页 | 关闭能力一览 | 替代原 ZR 关闭操作；返回后恢复父页提示 |
| 整理持有物品 | 当前物品列表向上 / 向下翻一页 | 切换左右物品菜单 | 替代原 ZL/ZR 切换菜单 |
| 出售 | 向上 / 向下翻一页 | 选中或取消选中当前物品，进行多项选择 | 替代原 ZR 多项选择 |
| 戒指·手镯图鉴 | 选择列表与能力列表向上 / 向下翻一页 | — | 无能力列表的戒指详情按一页切换条目 |

**转职列表：**考虑到职业排序操作使用频率较低，取消原 ZR 键的职业排序，将 ZR 用于向下翻页。右上角撤下旧排序提示，保留 L/R 切换单位提示。确认转职、取消、人物资格与所需物品遵循游戏规则。

**能力一览：**打开和关闭均使用右摇杆按下，窗口内部的 ZL/ZR 专用于翻页。窗口右上角显示右摇杆“关闭”与末尾翻页提示；返回戒指／手镯页后，右摇杆文案恢复为“能力一览”，并恢复该页其他按键提示。能力一览的可用条件、详细帮助和 B 键返回沿用游戏规则。

**整理持有物品与出售：**右上角分别显示右摇杆切换菜单、多项选择的说明，ZL/ZR 翻页提示放在最后。交换模式的菜单限制、出售类别切换、确认出售与总价计算遵循游戏规则。

**戒指·手镯图鉴：**选择列表、能力列表及没有能力列表的戒指详情均显示末尾翻页提示；原有图鉴选择、返回、类别与条目浏览操作保留。

## v0.2 新增内容：战前装饰品店与实时换装

### 入口位置

在尚未开始战斗的准备菜单中，选择 **“据点索拉涅尔”→“装饰品店”**。新增项目位于 **“锻造店”下方、“特技继承”上方**，不需要先返回索拉涅尔再换装。入口文案支持简体中文、繁体中文、日文和英文。

下图箭头标出了装饰品店入口，进入店铺后即可实时试穿。

![战斗准备菜单：据点索拉涅尔内新增装饰品店入口](images/sortie-accessory-shop-entry.jpg)

### 换装与预览

1. 从战前菜单进入装饰品店，选择购买或换装，再选择人物。
2. 在衣装或饰品列表移动游标，即可实时查看试穿效果；预览不等于确认装备。
3. 在支持预览操作的列表中，使用右摇杆旋转人物、调整远近，检查搭配。
4. 确认要装备的项目后退出店铺，返回战斗准备界面查看新的战场形象，再开始战斗。

预览复用原生装饰品店场景、相机、灯光和蓝色背景。切换人物或衣装时，新人物加载完成后再替换旧预览，减少加载期间的空窗。进入店铺时隐藏战场血条、头像、职业标记等画面元素，退出时恢复战场界面和镜头。

进出店铺采用原生淡出／淡入：进入时先淡出战场，等待店铺首个人物完成后淡入；退出时先淡出店铺，在换装人物的战场模型加载完成后淡入战场。淡出／淡入动画各约 **0.25 秒**，实际等待还取决于模型加载速度。

### 返回后的战场刷新

退出时比较进店前与最终装备，只刷新**已有战场模型且最终装备发生变化的我方人物**。七个可见分类全部纳入比较：衣装、头部、面部、背部、战场衣装、发色和风格。仅浏览试穿、未确认修改，或改后又恢复原装备，不触发额外刷新。

战前确认的换装通过返回刷新应用到当前战场形象，无需为普通换装重新出击。最终显示遵循游戏和所装服装 MOD 的模型规则；商品需提供对应资源，特殊变身与结合状态也有各自显示条件。

这一入口用于**战斗开始前的准备阶段**；战斗中的“结合时服装”设置是另一项功能，见下文。

## v0.1 功能

- 七个角色可用分类：衣装、头部、面部、背部、战场衣装、发色、风格（Mask 1/2/4/8/32/64/128）。Mask 16 不作为角色可用槽；底层八项存储与 version 1 存档格式保持。
- 七类菜单标签、购买分类筛选和当前装备摘要；未装备的摘要项隐藏。
- 为纹章士选人／编组／整备选人、斗技场、料理选人、支援与牵绊、外层持有物品、材料与贵重品、商店选人与购买、锻造／刻印／交换及拍照武器等列表加入 ZL/ZR 整页翻动；双列列表保持所在列。已继承特技和库存仅在 ZL/ZR 无原生用途的状态补翻页，保留原生帮助、类别切换等按键操作。
- 头部配饰与另类风格的镜头调整。
- “结合时服装”设置：角色当前服装／纹章士服装。已结合的地图形象需要重新结合或重新出击才能应用切换。

### 结合时服装设置

在“系统”→“环境设置”中，可选择“结合时服装：角色当前服装／纹章士服装”。

战斗中也可即时切换并观察到效果，但切换后已经结合的地图形象需重新结合或重新出击才能生效。龙化等特殊变身将保持现有规则不变。

## 诊断日志：默认关闭，需要时手动开启

插件默认**不创建或追加本插件的诊断日志**，正常使用无需配置。没有开关文件、文件无法读取，或去除首尾空白后内容不是 `on`（不区分大小写），都保持关闭。关闭日志不影响换装、菜单或战场刷新功能；这一开关只控制本插件，不会关闭 Cobalt、模拟器或其他 MOD 的日志。

### 开启日志

1. 完全退出游戏；模拟器环境先停止当前游戏进程。
2. 在 SD 卡根目录的 `engage` 文件夹内新建纯文本文件 **`fee-outfit-menu-debug.flag`**，注意实际文件名不要变成 `.flag.txt`。
3. 保存为 UTF-8 文本，内容只写下面一行：

   ```text
   on
   ```

4. 完整重启游戏，再复现需要排查的操作。

开关路径为 **`sd:/engage/fee-outfit-menu-debug.flag`**；日志追加到 **`sd:/engage/fee-outfit-menu-debug.log`**。模拟器使用其配置的虚拟 SD 卡目录，例如 `<虚拟 SD 卡目录>/engage/fee-outfit-menu-debug.flag`，而不是游戏 MOD 文件夹。

日志可检查战前菜单插入与进出店铺、预览请求及模型完成、场景和相机恢复、转场等待、人物刷新及七分类装备差异，以及语言、结合时服装设置、翻页和错误路径。具体记录随实际执行路径产生，不会每次操作都输出全部项目。

### 关闭日志

删除 `fee-outfit-menu-debug.flag`，或将内容改为 **`off`**，然后**完整重启游戏**。开关在本次进程首次读取后会缓存，运行中改文件不会即时生效。下次启动关闭后停止新日志；已有 `fee-outfit-menu-debug.log` 会保留，便于回看排查证据。需要整理时可在退出游戏后自行备份或删除旧日志。

## 下载与安装

插件文件：[`engage_outfit_menu_enhancements.nro`](Releases/engage_outfit_menu_enhancements.nro)；校验值见 [SHA256SUMS](Releases/SHA256SUMS)。

1. 先按 Cobalt 的说明安装基础运行环境。
2. 将 `engage_outfit_menu_enhancements.nro` 放入 SD 卡的 `engage/mods/engage-outfit-menu-enhancements/`。
3. 完整重启游戏后使用。模拟器环境对应其配置的虚拟 SD 卡目录。

安装后的文件位置：

```text
engage/mods/engage-outfit-menu-enhancements/engage_outfit_menu_enhancements.nro
```

升级时先完全退出游戏，再替换原 NRO，最后完整重启。已有配置与饰品存档格式沿用，无需删除存档。若服装整合包已包含本插件，使用包内版本并在该包中升级，避免同时加载独立副本。

## 兼容与使用范围

本编译版针对游戏 2.0.0 的菜单和函数实现，其他游戏版本不在当前兼容范围内。支持的翻页页面见各版本功能说明。已继承特技仍仅在不占用原生 ZL/ZR 帮助操作的状态下启用翻页；整理持有物品与出售的旧 ZL/ZR 操作已按上文改绑。

本插件提供衣装、饰品与菜单功能，实际可选商品和外观资源由游戏及所装服装 MOD 决定。截图中的追加服装与饰品不是本插件单独提供的商品。

版本变化见 [更新记录](CHANGELOG.md)。
